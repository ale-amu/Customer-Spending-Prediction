# Customer Spending Prediction

## Overview
This project analyzes the Online Retail dataset to predict whether customers are high spenders based on behavioral and transactional attributes. Using Python and Jupyter Notebooks, the analysis walks through data cleaning, exploratory data analysis, feature engineering, and classification modeling to uncover patterns in purchasing behavior.

## Dataset
- **Source:** Online Retail Dataset (UCI Machine Learning Repository)
- **Size:** Transactional retail data with attributes including customer ID, invoice details, quantity, unit price, and country

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Data Visualization (Matplotlib/Seaborn)
- Machine Learning / Classification Modeling

## Key Steps
1. **Data Cleaning** — Handled missing values, removed duplicates, and standardized data formats
2. **Exploratory Data Analysis** — Identified spending patterns and trends across customer segments
3. **Feature Engineering** — Constructed target variable and relevant features from raw transactional data
4. **Modeling** — Built and evaluated classification models to predict high-spending customers

## Skills Demonstrated
- Data extraction, transformation, and cleaning
- Exploratory data analysis and visualization
- Predictive modeling and model evaluation
- Working with structured real-world datasets
